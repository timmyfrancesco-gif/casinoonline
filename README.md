# OrderVault 🔐

**Gestione ordini futuristica** per CNFans, OopBuy, Pandabuy, Sugargoo e oltre.

## Features

- 🔐 **Codice stanza a 6 cifre** — Crea o unisciti a una stanza
- 🔗 **Link prodotto** — Incolla il link diretto da qualsiasi piattaforma
- 💰 **Prezzo & Peso** — Traccia costo e peso stimato per ogni ordine
- 🖼️ **Galleria foto** — Trascina immagini o caricale dal dispositivo
- 📊 **Statistiche live** — Totale ordini, prezzo aggregato, peso totale
- ✏️ **Modifica & elimina** — Gestisci i tuoi ordini in tempo reale
- 💾 **Offline-first** — Dati salvati in localStorage, nessun server

## Design

- Particelle interattive con repulsione del cursore
- Glassmorphism + effetti neon cyan/purple
- Scroll reveal animations
- Scanlines & vignette overlay futuristico
- Font Orbitron + Rajdhani + Share Tech Mono
- Completamente responsive (mobile-first)

## Come usare

1. Apri `index.html` nel browser
2. Clicca **Crea Stanza** → ottieni il codice a 6 cifre
3. Condividi il codice con chi vuoi
4. Clicca **+ Ordine** e inserisci i dettagli
5. Per unirsi: clicca **Unisciti** e inserisci il codice

## Stack

- HTML5 / CSS3 / Vanilla JavaScript (zero dipendenze)
- Canvas API per le particelle
- Intersection Observer per le scroll animations
- localStorage per la persistenza dei dati
